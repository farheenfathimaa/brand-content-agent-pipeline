## Interpretation and limits

- **Mock mode uses deterministic fake providers.** These numbers exercise the harness, state machine, guardrails, revision loop, and translation check. They are **not** evidence of live LLM writing quality.
- The mock judge is a transparent heuristic over the guardrail report, not a live LLM judgment. The live judge prompt is versioned under `app/prompts/judge/` and only runs with `APP_MODE=live`.
- The mock translator uses a small dictionary and a language marker. Similarity is high by construction. It verifies wiring, not translation quality.
- Back-translation similarity is **lexical**, not semantic. It catches gross omissions and drift, not subtle mistranslation.
- Groundedness checks digits and a fixed list of promotional claim patterns. Spelled-out numbers and novel claim phrasings can evade it.

This report is generated by `python -m app.evals.runner` (or `make eval`). Every value above comes from the run that produced this file.
